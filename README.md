# I.C.A.N. 我也可以 AI 教室

**I**magine · **C**reate · **A**I · **N**ow

國小老師做給老師的 AI 研習、學生營隊與校園小工具。名稱念起來就是 *I can*，也就是每堂課的流程：

| 字母 | 意思 | 在課堂上 |
| --- | --- | --- |
| **I** | Imagine | 想清楚需求：給誰用、何時用、按下去會怎樣 |
| **C** | Create | 動手做出來，一次只改一件事 |
| **A** | AI | 和 AI 協作，不用先學程式語言 |
| **N** | Now | 現在就用，下週帶進教室 |

## 桌上 AI 機器人（`robot/`）

可用學校 3D 印表機列印的桌上機器人，三個版本都尚未實機試印，先印測試件再調參數。

| 版本 | 資料夾 | 動作 | 主要零件 |
| --- | --- | --- | --- |
| v0.1 轉頭版 | `robot/v0.1-turn-head/` | 左右轉頭、點頭 | CoreS3 SE 或 ESP32-S3 散件、SG90 ×2 |
| v0.2 走路版 | `robot/v0.2-walking/` | 雙腳行走 | CoreS3 SE、SG90 ×4 |
| v0.3 平衡版 | `robot/v0.3-balance/` | 兩輪自平衡 | CoreS3 SE、ESP32-S3、N20 編碼馬達 ×2、MPU6050、TB6612 |

每個資料夾內有 STL、預覽圖與組裝說明。模型為參數化 Python 程式（`robot/src/`），改上方參數即可重新輸出：

```
pip install manifold3d trimesh numpy
cd robot/src
python3 build.py out      # v0.1
python3 biped.py out      # v0.2
python3 balance.py out    # v0.3
```

列印建議：PLA、層高 0.2 mm、3 層牆、填充 15–20%，免支撐。
