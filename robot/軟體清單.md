# 軟體清單

全部都是免費軟體。打 ★ 的是一定要裝的。

## 1. 建模（改尺寸時才需要）

| 軟體 | 用途 | 取得 |
| --- | --- | --- |
| Python 3.10 以上 | 執行建模程式 | python.org |
| numpy、manifold3d、trimesh | 產生 STL 的套件 | 在 `4_原始碼` 資料夾執行 `pip install -r requirements.txt` |
| matplotlib | 產生預覽圖（可不裝） | 同上 |

改尺寸流程：打開 `build.py`（或 `biped.py`、`balance.py`）最上方的參數 → 存檔 → 執行 `python3 build.py out`，新的 STL 會出現在 `out` 資料夾。這一步也可以請 AI 幫你改參數。

## 2. 切片與列印

| 軟體 | 用途 | 說明 |
| --- | --- | --- |
| ★ 學校 3D 印表機的原廠切片軟體 | 把 STL 轉成印表機看得懂的檔案 | 例如 Bambu Studio、UltiMaker Cura、PrusaSlicer、FlashPrint，依學校機型選 |

## 3. AI 語音（讓機器人會聽、會說、會動）

| 軟體 | 用途 | 說明 |
| --- | --- | --- |
| ★ 小智 AI 韌體（xiaozhi-esp32） | 機器人的大腦：語音喚醒、對話、表情、控制馬達 | 開源，支援 CoreS3 與 ESP32-S3；裝置端用 MCP 控制伺服馬達 |
| 小智網頁燒錄工具或 ESP-IDF 5.x | 把韌體燒進板子 | 用現成韌體只要網頁燒錄；要改程式才裝 ESP-IDF |
| xiaozhi.me 控制台 | 設定 AI 模型、角色、聲音 | 預設連官方伺服器，最快上手 |
| xiaozhi-esp32-server（自架，選用） | 學校自己的 AI 後端 | 開源 Python 伺服器，可接自選的大型語言模型；學生資料不經外部平台，學校使用建議自架 |
| M5Stack StackChan 官方韌體（參考） | CoreS3 + 雙伺服馬達頭部的現成範例 | 結構和 v0.1 很像，可參考它的馬達控制寫法 |

## 4. 動作程式（走路、平衡）

| 軟體／函式庫 | 用在 | 用途 |
| --- | --- | --- |
| ★ Arduino IDE 2 | v0.2、v0.3 | 寫動作程式、燒錄 ESP32 |
| ★ ESP32 板子套件（Espressif） | v0.2、v0.3 | 在 Arduino IDE 的「開發板管理員」安裝 |
| M5Unified | v0.2 | CoreS3 SE 的螢幕、喇叭、按鍵控制 |
| ESP32Servo | v0.1、v0.2 | 控制 SG90 |
| Otto DIY 函式庫 | v0.2 | 現成的走路、跳舞動作，可直接改 |
| MPU6050 函式庫（如 Adafruit MPU6050） | v0.3 | 讀取傾斜角度 |
| ESP32Encoder | v0.3 | 讀取 N20 編碼器轉速 |
| UIFlow 2（選用） | 營隊、學生 | M5Stack 的積木程式，適合學生先玩 CoreS3 SE |

## 5. 驅動程式

CoreS3 SE 和 ESP32-S3-DevKitC-1 都用原生 USB，Windows 10/11 通常不用另外裝驅動。若電腦認不到板子，再依開發板上的 USB 晶片安裝 CH343 或 CP210x 驅動。

## 建議安裝順序

1. 切片軟體 → 先把零件印出來
2. 小智網頁燒錄 → 先讓機器人會說話
3. Arduino IDE + 函式庫 → 再讓它動起來
4. 需要改尺寸時才裝 Python 建模環境
