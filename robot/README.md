## 先試印的零件（避免整套白印）

1. **v0.1**：先印 yoke 和 head，測 SG90 與舵盤的配合。低價方案買到螢幕後量 PCB，調整頭部內腔。
2. **v0.2**：先印 1 隻 leg + 1 隻 foot，測腳踝馬達與舵盤。
3. **v0.3**：先印 wheel，測 N20 的 D 軸鬆緊；買到馬達後量總長與孔距再印身體。

SG90 各廠尺寸略有差異，量到不合時改 `4_原始碼/build.py` 最上方的 `SG_` 參數，重新產生 STL（見軟體清單第 1 節）。

## 組裝重點

**v0.1 轉頭版**
1. 兩顆馬達先用程式轉到 90°（置中）再裝舵盤。
2. 左右轉的馬達裝在底座內，轉軸朝上；舵盤嵌進 U 型支架底部。
3. 點頭馬達裝在支架右臂，左臂用 M3 螺絲當樞軸。
4. 板子從頭部上方插入，蓋上頂蓋；線從支架走線孔進底座。
5. 底板有配重槽，可放 10 元硬幣增加穩定。

**v0.2 走路版**
1. 四顆馬達先轉到 90° 再裝舵盤。
2. 腳踝馬達從腿內側裝進前牆，轉軸朝前，鎖耳朵；腳板立柱貼上腳踝舵盤。
3. 髖馬達倒裝進身體底板（轉軸朝下）；腿頂面嵌槽對準髖舵盤鎖上。
4. 線從身體背面開口進入，最後插入 CoreS3 SE、蓋頂蓋。
5. 馬達用另一組 5V 電源，地線要和 CoreS3 SE 接在一起。

**v0.3 平衡版**
1. 兩顆 N20 背對背裝在身體底部，M1.6 螺絲固定；輪子用 M2 止付螺絲鎖 D 軸。
2. ESP32-S3、MPU6050、TB6612FNG 裝在背蓋內側；MPU6050 要水平、靠近輪軸。
3. 18650 電池座在馬達上方，經升壓板供 5V。
4. CoreS3 SE 從上方插入，與 ESP32-S3 用 UART（TX/RX 交叉、共地）連線。
5. 輪子外圈溝槽套 O 型環當輪胎。
